# USE CASE: 1 Produce a Report on all the countries of the world, a specific continent or specific region organised by population

## CHARACTERISTIC INFORMATION

### Goal in Context

As a *data analyst* I want *to find the population in countries from biggest to smallest in the world, region and continent* so that *I can make a report for future planning.*

### Scope

system.

### Level

user goal.

### Preconditions

Database contains country population data and data for the country report.

### Success End Condition

many country reports are available for data analyst to add data to reports.

### Failed End Condition

No reports are produced.

### Primary Actor

data analyst.

### Trigger

data analyst runs the program.

## MAIN SUCCESS SCENARIO

1. data analyst runs program.
2. data analyst stores the data produced by the program.
3. data analyst adds data to report.


## EXTENSIONS

1. **no data is produced**:
    1. analyst informs developers of issue.

## SUB-VARIATIONS

1. The area is the world.
2. The area is a continent.
3. The area is a region.
